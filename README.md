# Ralgos

**Ralgos** is a C++/Python hybrid library for building, analyzing, and amplifying randomized algorithms. It supports various generators, custom random variables definition and sampling, and inference tools like Chernoff, Hoeffding bounds.

---

## Documentation
For documentation refer to [Ralgos Documentation](https://nimittnim.github.io/ralgosweb/ralgolib.html).

---

## Requirements
pybind11, scikit-build

## Installation

```bash
git clone https://github.com/nimittnim/ralgos.git
cd ralgos
pip install .
```
